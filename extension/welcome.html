Welcome to Tab Steer

Tab Steer lets a command-line tool on this computer control the tabs you choose to share. It needs a small companion program to work.

Checking

  1. Install the companion

    In a terminal (Node.js 18 or newer required):

    npm install -g tabsteer
tabsteer install

    The status above turns green within a minute of installing. Run tabsteer doctor if it does not.

  2. Share a tab

    Open a page, click the Tab Steer icon in the toolbar and choose Share this tab with your agent. Shared tabs sit in a tab group named "Tab Steer". Tab Steer starts with access to no sites, so you allow each site the first time.

  3. Let your agent use it

    Any agent that can run a shell command can now run tabsteer read, tabsteer click and the rest. The toolbar icon also has a Pause button that stops everything.
