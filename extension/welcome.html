Welcome to Tab Steer

Tab Steer lets the coding agent on this computer work in the tabs you share, on the sites you allow. Two quick steps get it ready.

  1. Install the companion Not connected

    Paste this into a terminal (Node.js 18 or newer):

    npm install -g tabsteer && tabsteer install

    This step turns green within a minute. If it doesn't, run tabsteer doctor.

  2. Turn on Tab Steer Off

    Chrome asks once to let Tab Steer reach websites. Your agent still only gets the tabs you share, on the sites you allow.

  3. Share a tab

    On any page, click the Tab Steer icon in the toolbar and choose Share this tab with your agent. That also allows the site. Shared tabs sit in a tab group named "Tab Steer", and Activity shows everything your agent does. Pause stops it at once.
